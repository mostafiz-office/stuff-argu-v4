# Slide 04 — Features Comparison
**Component**: `TierDetailSlide` → `src/slides/TierDetailSlide.tsx`
## Overview
Apple-inspired comparison experience for Growth, Skilled, and Leadership. Large persistent tier headers sit above a dedicated vertical scroll region containing all 14 features in three labeled groups. Tier labels use text-only badges. Hovering a row highlights the full row, while hovering a tier header or cell highlights that tier's complete column.
