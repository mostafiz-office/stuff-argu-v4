# Global Toast Notification System

> **Source**: Sonner library.

## 1. Library

Sonner — minimal toast notifications for React.

## 2. Usage Patterns

| Event | Toast Type | Message |
|-------|-----------|---------|
| Share link copied | Success | "Link copied to clipboard" |
| Export started | Info | "Generating..." |
| Export complete | Success | "Download ready" |
| Export error | Error | "Export failed" |

## 3. Positioning

Default Sonner positioning — bottom-right of viewport.
