# Global Export & Download System

> **Source**: `html2canvas`, `jspdf`.

## 1. Export Capabilities

| Format | Method |
|--------|--------|
| PNG Image | html2canvas capture of current slide |
| PDF | jspdf with html2canvas rendered pages |

## 2. Capture Settings

| Property | Value |
|----------|-------|
| Background | `#0a0a12` (matches `--pres-bg`) |
| Scale | `2` (for retina) |
| Width | `1920px` |
| Height | `1080px` |
