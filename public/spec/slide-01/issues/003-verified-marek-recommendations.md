# Issue 003 — Recommendation Cards Misattributed to Marek

## Problem
Both alternating covers reused two generic quotes while showing Marek's own name and portrait as the recommender. The cards therefore did not identify the people who wrote the recommendations.

## Verified Source
The supplied LinkedIn screenshot showed recommendations about Marek from Cristian Stancalău, Jakub Szubarga, Adam Lewkowicz, and Alim Ul Karim. The user supplied separate portrait crops for Cristian, Jakub, and Adam and explicitly excluded Alim's recommendation.

## Fix
- Cover V1 shows Cristian and Jakub.
- Cover V3 shows Adam and repeats Cristian as the selected shared recommendation.
- Each card uses the actual recommender's portrait, name, role, and a shortened exact excerpt.
- Only the strongest phrase receives amber emphasis.
- Every card links to Marek's LinkedIn recommendations page.

## Prevention Rule
Recommendation cards must identify the author of the recommendation, never the person being recommended. Do not invent or paraphrase testimonial claims when the exact source is unavailable.

## Follow-up — 2026-10-08
Both alternating covers now show two recommendations. Cristian was selected as the shared recommendation because his delivery-leadership outcome complements Adam's trust-focused quote on Cover V3. The shared card reuses the same verified data and portrait.
