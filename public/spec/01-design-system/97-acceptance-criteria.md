# Acceptance Criteria — Design System

**Version:** 1.0.0  
**Updated:** 2026-04-09

---

## Criteria

| # | Criterion | Testable |
|---|-----------|----------|
| 1 | All slide backgrounds use `.slide-dark-bg` class | ✅ |
| 2 | All slides wrap content in `<ScaledSlide>` | ✅ |
| 3 | All slides include `<SlideHeader />` | ✅ |
| 4 | No hardcoded hex colors in component styles (except per-tier data palette) | ✅ |
| 5 | All headings use `font-family: 'Ubuntu'` | ✅ |
| 6 | All body text uses `font-family: 'Poppins'` | ✅ |
| 7 | All content animations use Framer Motion `motion` components | ✅ |
| 8 | Slide content is authored in 1920×1080 coordinate space | ✅ |
| 9 | CSS custom properties use HSL format without wrapper | ✅ |
| 10 | Z-index layering follows documented hierarchy | ✅ |
