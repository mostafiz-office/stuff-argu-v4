# Export System

**Version:** 1.0.0  
**Updated:** 2026-04-04  
**Status:** Complete

---

## Overview

The export system allows users to download the presentation as PDF, individual slide images, or animated HTML files. Export functionality is gated behind the `?export=1` query parameter.
